# 景区观光车双向循环调度模拟

## 项目简介

本项目是数据结构与算法课程设计，使用 C 语言实现景区观光车双向循环调度模拟。

景区中的多个站点按照环形排列，观光车根据指定的正向、反向步数交替运行，并在停靠站点进行游客上下客操作。程序支持临时关闭站点，模拟实际调度过程。

## 主要功能

- 录入站点编号、名称和等候游客数量。
- 设置站点总数 P、正向步数 M、反向步数 N 和最大停靠次数 Q。
- 按照正向、反向交替运行的规则模拟观光车调度。
- 支持临时关闭站点，关闭站点不参与有效站点计数。
- 模拟游客上下客并更新相关数据。
- 记录停靠过程，输出调度结果。
- 处理无法找到有效停靠站点等异常情况。

## 数据结构与算法

**1. 数组模拟环形站点**

使用数组保存站点信息，通过取模运算实现首尾相连的环形结构。

**2. 双向循环调度**

使用方向变量控制正向或反向运行。观光车按照 M、N 两种步数交替移动，并在完成一次停靠后改变方向。

**3. 临时关闭站点处理**

移动过程中判断站点是否开放，跳过关闭站点，只统计有效开放站点。

**4. 调度记录**

按照停靠顺序保存调度信息，便于展示运行过程和最终结果。

## 开发环境

- 编程语言：C
- 开发工具：Visual Studio
- 项目类型：Windows 控制台程序

## 运行方法

1. 下载或克隆本仓库。
2. 使用 Visual Studio 打开 `景区观光车双向循环调度模拟.sln`。
3. 编译并运行项目。
4. 根据控制台提示输入站点信息及 P、M、N、Q。
5. 查看调度过程和最终统计结果。

## 项目说明

本项目主要用于学习数组、循环结构、模块化函数设计及环形调度算法，属于课程设计模拟程序。
